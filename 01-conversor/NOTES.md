# 01-conversor

## Spec (5 líneas)

CLI para convertir unidades de:

- temperatura entre Celsius, Fahrenheit y Kelvin. El usuario ingresa un valor y la unidad de origen, y el programa devuelve el valor convertido a las otras dos unidades.
- longitud entre metros, kilómetros, millas y pies. El usuario ingresa un valor y la unidad de origen, y el programa devuelve el valor convertido a las otras tres unidades.
- peso entre kilogramos, libras y onzas. El usuario ingresa un valor y la unidad de origen, y el programa devuelve el valor convertido a las otras dos unidades.

El programa debe manejar entradas inválidas y mostrar un mensaje de error adecuado. Además, debe permitir al usuario realizar múltiples conversiones hasta que decida salir.El programa debe ser fácil de usar y tener una interfaz clara y amigable.
El programa debe preguntar por el tipo de conversión que desea realizar (temperatura, longitud o peso) y luego solicitar el valor y la unidad de origen.Si hay algún error en la entrada, el programa debe mostrar un mensaje de error y permitir al usuario volver a intentarlo.
Si el usuario desea salir, puede presionar la tecla 'q' o 'Q' en cualquier momento para finalizar el programa. el valor y la unidad van en entradas separadas

En este vamos a practicar los conceptos básicos de golang, como la sintaxis, las funciones, los tipos de datos y el manejo de errores. Además, vamos a trabajar con la entrada y salida de datos en la consola y a implementar un bucle para permitir múltiples conversiones.
